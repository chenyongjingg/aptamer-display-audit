You are auditing a preclinical cancer-therapy paper for reporting completeness.

Extract the following 16 fields. For each field return exactly one status:
- "reported": the document states a value (or an explicit qualitative fact for categorical fields).
- "not_reported": the document does not state it.
- "not_applicable": the field cannot apply to this study (e.g. in-vivo fields in a purely in-vitro study).

Fields:
1. kd: apparent dissociation constant; unit nM/uM/pM; include method/buffer/temperature if stated.
2. id_per_g: normalized tumour accumulation (%ID/g); include time point and organ if stated.
3. half_life: half-life or clearance; unit h or mL/h/kg.
4. dose: administered dose with unit (mg/kg, nmol/kg, etc.) and route if stated.
5. route: i.v., i.p., s.c., intravesical, oral, etc.
6. time_points: time points at which a PK/biodistribution readout was measured.
7. numeric_efficacy: a numeric % tumour growth inhibition or % cell inhibition.
8. serum_stability: degradation half-time or stability in serum, with conditions.
9. valency: integer number of aptamers/ligands per construct (or a designed ratio).
10. spacing: ligand-ligand distance or spacing in nm.
11. linker_length: linker/spacer length in nt.
12. linker_chemistry: linker/spacer chemistry (e.g. poly-A, PEG, TEG).
13. size: construct size in nm, with method if stated.
14. attachment: attachment site/orientation (vertex, edge, face, 5' end, 3' end, etc.).
15. comparator: a free-aptamer, monovalent, naked or other comparator arm.
16. immune: CpG content or any innate-immune/cytokine readout.

Rules:
- Every value MUST carry a verbatim quote copied exactly from the document. Do not paraphrase.
- The quote must contain the value string.
- If a value is absent, do NOT infer it from general knowledge. Use "not_reported".
- If multiple values are reported (e.g. several Kd values), return all of them.
- Context (buffer, temperature, method, cell line, time point, route) is part of the value when stated.

Return ONLY a JSON object with exactly these 16 keys. Each key maps to:
{"status": "...", "values": [{"value": "...", "unit": "...", "quote": "...", "context": {...}}], "absence_evidence": "..."}
